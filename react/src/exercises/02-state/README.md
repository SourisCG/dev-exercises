# 02 - Counter

`useState` + events.

## What to do

1. Open `Counter.tsx`
2. Finish the `TODO`
3. See it: `pnpm dev` → Open 02
4. Check: `pnpm test 02-state`

## Rules

* Show exactly `Count: 0` at start
* Buttons must say exactly `+1`, `-1`, `Reset`

## New words

* `state` = value React remembers. `useState(0)` starts at 0.
* `event` = user action. `onClick` runs on click.
* Every click -> React shows the page again with the new value.
