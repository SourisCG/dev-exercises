# 01 - Profile Card

## What to do

1. Open `ProfileCard.tsx`

## Rules

* Show name in `<h2>`
* Show exactly `Age: 36` in `<p>`
* Show email, or exactly `no email`

## New words

* `component` = function that returns HTML
* `props` = input of the component
* `render` = show on screen
