# 01 - Hello Input

First program! Very easy.

## What to learn

* `let` - make a variable
* `mut` - variable can change
* `String` - text
* `println!` - print to screen
* `read_line` - read from keyboard

## What to do

1. Run: `cargo run`
2. The program asks your name. Type your name.
3. It says hello to you.
4. Then do the TODO tasks in `src/main.rs`.

## Tasks

- [x] Task 1: Run the program, it works
- [x] Task 2: Make function `greet` pass the test (`cargo test`)
- [x] Task 3 (bonus): Ask age too. Print age next year.

## New words

* `input` = what user types
* `output` = what program prints
* `function` = small machine that does one thing

When `cargo test` is green, go to `02-calculator`!
