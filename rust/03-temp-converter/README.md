# 03 - Temp Converter

Convert Celsius <-> Fahrenheit.

Formula:
* C to F: F = C * 9/5 + 32
* F to C: C = (F - 32) * 5/9

## What to learn

* Write clean functions
* Write tests
* `cargo test` to check

## What to do

1. Open `src/main.rs`
2. Finish `c_to_f` and `f_to_c`
3. `cargo test` must be green
4. `cargo run`, try: `25 C` or `77 F`

## Tasks

- [x] Task 1: both functions work
- [x] Task 2: program runs without crash
- [x] Task 3 (bonus): Add Kelvin. K = C + 273.15

## New words

* `convert` = change from one to other
* `formula` = math rule
