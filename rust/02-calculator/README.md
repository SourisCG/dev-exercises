# 02 - Calculator

Make a calculator!

## What to learn

* `fn` - make a function
* `f64` - decimal number (like 3.14)
* `match` - choose one option
* `Result` - Ok (good) or Err (error)
* `Option` - Some value or None

## What to do

1. Open `src/main.rs`
2. Finish the 4 functions: `add`, `sub`, `mul`, `div`
3. Run tests: `cargo test`
4. Run program: `cargo run` and try: `5 + 3`

## Tasks

- [x] Task 1: `add`, `sub`, `mul` work
- [x] Task 2: `div` returns error if divide by 0
- [x] Task 3 (bonus): Add `%` (remainder) and `^` (power)

## Example

```
> 10 / 2
= 5
> 10 / 0
Error: cannot divide by zero
```
