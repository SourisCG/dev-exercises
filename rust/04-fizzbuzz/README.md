# 04 - FizzBuzz

Classic job interview exercise!

Rules:
* Number % 3 == 0 and % 5 == 0 -> "FizzBuzz"
* Number % 3 == 0 -> "Fizz"
* Number % 5 == 0 -> "Buzz"
* Else -> the number, like "7"

## What to learn

* `for` loop
* `%` remainder
* `if / else if / else`
* `String` vs `&str`

## What to do

1. Finish function `fizzbuzz(n)` in `src/main.rs`
2. `cargo test` must be green
3. `cargo run` prints 1 to 100

## Tasks

- [ ] Task 1: function works
- [ ] Task 2: program prints 1..100 correct
- [ ] Task 3 (bonus): Do it with `match` instead of `if`

Example output:
```
1
2
Fizz
4
Buzz
Fizz
...
14
FizzBuzz
```
